Both features were developed collaboratively through pair programming.

Working inside an existing codebase meant that a significant part of the development process involved understanding systems that had already been established by the team.
For Octodrone, this meant learning how the existing ForceSystem and enemy architecture interacted before extending it for ground-based behavior.
For Radial Stamina, it meant stepping outside my usual code-focused workflow and learning how gameplay data could drive a visual system through ShaderGraph.

## Takeaway

Operation Starfall was a pivotal project in my game development journey and the oldest in my portfolio.
It marked my turning point, where I've picked up foundational skills that I still apply daily as a developer.
To name a few examples: SOLID principles such as writing maintainable code and why we strive to do so.
Documenting your work, refactoring, SCRUM, User Testing, Shaders & Rendering.

A big thank you to Alex Kentie and Berend Weij,
whose guidance was very enlightening throughout- and beyond this project.
Their mentorship has opened up my eyes to new areas of game development I hold dearly and am still actively exploring!
