About Octodrone

Octodrone was the first ground-based enemy developed for Operation Starfall. Its design combined state-driven AI, animation cycles, and responsive attack logic.

Animator & Jump Cycle

I integrated Unity Animator triggers with the enemy state machine, making sure Octo’s Idle, Walking, Jumping, Attacking, and Fuzzy states transitioned smoothly. Unity Events were used to time animation transitions such as JumpUp → JumpTop → JumpAttack.

Patrolling & Detection Logic

I worked on the patrol and detection system through pair programming. The original patrol code was tuned for flying enemies (A*-based pathfinding). We adapted that patrol logic to suit a ground-based enemy—converting positional math and movement to ground-friendly vectors, iterating prefabs and conditions, and debugging transitions like Patrol → Detect → Attack using Unity Events and breakpoints.

Prefab & Polish

Later I focused on refining Octo’s prefab—adjusting animator tile timings, adding Unity Events for more reliable transitions, and removing redundant code. I collaborated with the technical director and other devs on these changes (especially the patrol rewrite) to stabilize behavior.

Takeaway

Octodrone was a complex learning experience in AI state machines, Unity Animator workflows, and debugging with event-driven triggers. My main contribution was getting Octo to patrol, detect, and attack consistently while polishing prefab behavior and animation timing.

JumpState: Octo's unique attack state

This script inherits from the base AttackState.cs.
Sequence overview:

  1. 1. Disable gravity and apply an amplified upward force so Octo jumps.
  2. 2. On a mid-air event (e.g. jump top), re-enable gravity and apply a forward force toward the player's position.
The JumpState coordinates animation events and state transitions so the attack plays reliably.

The hardest parts were understanding the ForceSystem and the state machine interactions. After lots of debugging, iterations, and teamwork, Octo's behavior became stable and feels natural in-game.
